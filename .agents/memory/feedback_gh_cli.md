Use the gh CLI for GitHub operations (viewing repos, fetching file contents, etc.).

**Why:** User preference for gh CLI over other methods.
**How to apply:** When browsing GitHub repos, use `gh repo view`, `gh api`, `gh repo clone` etc. instead of curl/WebFetch against github.com URLs.
